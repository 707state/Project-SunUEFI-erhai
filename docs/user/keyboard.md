# 官方键盘的功能键

磁吸键盘没有独立的 F1–F12 键，使用 **右 Ctrl + 顶排数字键**：

| 组合键 | 功能键 |
| --- | --- |
| 右 Ctrl + `1`～`9` | F1～F9 |
| 右 Ctrl + `0` | F10 |
| 右 Ctrl + `-` | F11 |
| 右 Ctrl + `=` | F12 |

先按住右 Ctrl，再按对应键。`-` 和 `=` 指顶排 `0` 右边的两个键。
左 Ctrl 和右 Ctrl 配合使用，可以输入 Ctrl + F1 等组合；Shift 也可以叠加。
右 Ctrl 与其他按键的组合保持原有行为。

Linux 内核键盘驱动输出标准功能键，无需为 GNOME、KDE 或 Minecraft 分别配置快捷键。
例如 Minecraft 中可用右 Ctrl + `3` 调出 F3 调试界面。
此映射适用于官方磁吸键盘，不改变外接 USB／蓝牙键盘。

需要使用包含此改动的 Linux 内核和 UEFI 固件；仅更新桌面或 Android 助手的网页资源不会生效。

UEFI 输入解析器已加入同一映射；磁吸键盘的底层接入仍在完善，BIOS 中暂不能保证可用。
