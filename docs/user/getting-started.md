# 快速上手

安装顺序是：**安装模块 → 打开助手 → 分区 → 刷写 ESP 和 root → 启动 Linux**。已有独立分区时跳过分区。

完整步骤和下载说明见[安装指南](install-from-artifact.md)，首次分区的当前限制见[已知问题](known-issues.md#首次分区)。

Linux 默认用户名为 `piano`，密码为 `piano123456`，桌面自动登录。锁屏和 `sudo` 使用这个密码，可在系统设置中修改。

[电脑安装](install-from-computer.md)和[临时启动固件](temporary-boot.md)是备用方式；无法启动时查看[故障恢复](recovery.md)。
